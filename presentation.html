🗄️ Database Design
3 Tables — Complete Data Architecture
📋 users
id INT · PK · Auto
full_name VARCHAR(100)
email VARCHAR · Unique
password VARCHAR · Hashed
role ENUM · user/admin
created_at TIMESTAMP
Registered users ka data store hota hai. Password encrypted hota hai.
📚 faqs
id INT · PK · Auto
question VARCHAR(500)
answer TEXT · Long
category VARCHAR(50)
difficulty Easy/Medium/Hard
tags VARCHAR(255)
views INT · Counter
Interview questions + answers. FULLTEXT INDEX for fast search.
📊 search_analytics
id INT · PK · Auto
query_text VARCHAR
field_category VARCHAR
difficulty VARCHAR
matched_results INT · Count
is_unresolved BOOLEAN
searched_at TIMESTAMP
Har search ka log. is_unresolved track karta hai kahan answer nahi mila.

User Registration & Login System
📝 Registration Flow
1️⃣ User naam, email, password deta hai
2️⃣ Email format validate hota hai
3️⃣ Duplicate email check hota hai
4️⃣ Password encrypt hota hai (bcrypt)
5️⃣ MySQL mein INSERT hota hai
6️⃣ ✓ Account ready! Dashboard pe redirect
🔑 Login Flow
1️⃣ Email + Password enter karo
2️⃣ DB se user record fetch hota hai
3️⃣ password_verify() se match check
4️⃣ Session localStorage mein save hoti hai
5️⃣ Role check — user / admin?
6️⃣ ✓ Dashboard ya Admin Panel!
🔐 Security: PHP password_hash() — bcrypt algorithm use hoti hai. Plain text password kabhi store nahi hota. PDO Prepared Statements se SQL Injection impossible hai.

🔐 Security Features
Project Secure kyun hai?
🔐
Password Hashing (bcrypt)
PHP password_hash() + password_verify() — plain text kabhi store nahi hota. Agar DB hack bhi ho, passwords safe rehenge.
🛡️
SQL Injection Protection
PDO Prepared Statements use hote hain — user input directly query mein kabhi nahi jaata. Hacker SQL inject nahi kar sakta.
✅
Input Validation
Server-side email validation filter_var(), empty field checks, email uniqueness check — sab backend pe hota hai.
👑
Role-Based Access Control
Admin panel sirf role='admin' users ko milta hai. Frontend + Backend dono jagah check hota hai.
🌐
CORS Headers
Cross-Origin Resource Sharing headers set hain — unauthorized domains se API access control hota hai.
🏠
Environment Auto-Detection
db.php automatically detect karta hai — localhost hai ya live server. Alag credentials use hote hain automatically.
